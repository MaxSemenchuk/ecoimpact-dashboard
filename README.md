# Ukraine Ecovillage Impact Dashboard

An open, bilingual (EN / UK) dashboard for the ecovillage network of Ukraine: what the villages **produce and restore** (solar energy, trees, water), how they **trade and help each other** (local vouchers), what **funding** they raised, and which **birds** are heard around them. Every figure comes from a public blockchain or platform, so anyone can check it.

**Live:** https://ecoimpact.genukraine.com.ua

> Українською: відкрита двомовна панель впливу екопоселень України — сонячна енергія, відновлення природи, місцева економіка, фінансування та моніторинг птахів. Усі цифри беруться з публічних блокчейнів і платформ. Нижче — як запустити, оновити дані й адаптувати панель для своєї мережі.

It is a plain static site — HTML, [Tailwind](https://tailwindcss.com) (CDN), [Chart.js](https://www.chartjs.org), [Leaflet](https://leafletjs.com) + [MapLibre](https://maplibre.org). No build step, no framework, no backend.

## Data sources

| Block | Source | How it is loaded |
|---|---|---|
| Solar energy | [Arkreen](https://arkreen.com) (DePIN solar meters, AKRE rewards) | snapshot: `data/arkreen-miners.json`, `data/arkreen-monthly.json` |
| Verified impact claims | [Hypercerts](https://hypercerts.org) on Celo | snapshot: `data/hypercerts.json` |
| Tree planting projects | [Silvi](https://silvi.earth) public API | snapshot: `data/silvi.json` |
| Eco-credit sales | INAT marketplace on Celo (via [Blockscout](https://celo.blockscout.com)) | snapshot: `data/inat.json` |
| Local economy | [Sarafu Network](https://sarafu.network) vouchers, pools and activity reports | snapshots: `data/sarafu-pools.json`, `data/sarafu-reports.json` |
| Donations | [Giveth](https://giveth.io) | static values in `js/api.js` (`BLOCKCHAIN_CONFIG.giveth`) — update by hand |
| Grants | [Karma](https://www.karmahq.org) (GAP API) | live, in the browser |
| Bird monitoring | [BirdWeather](https://www.birdweather.com) stations | live, in the browser |

Browsers are rate-limited by Blockscout (HTTP 429), and some APIs do not allow cross-origin requests, so most data is **pre-fetched into JSON snapshots** by the scripts below and served as static files. Karma and BirdWeather allow browser requests and are read live. If a snapshot is missing, the page falls back to a live request or to the demo values in `js/data.js`.

## Run it locally

```bash
cd dashboard
python3 -m http.server 8000
# open http://localhost:8000   (add ?lang=uk for Ukrainian)
```

Any static file server works. To deploy, publish the `dashboard/` folder (a `vercel.json` with `outputDirectory: dashboard` is included).

## Update the data

Scripts need Node.js 18+ (and `bash`, `curl`, `python3` for the two `.sh` scripts). Run them from the repository root; each one rewrites a file in `dashboard/data/`.

```bash
bash scripts/fetch-arkreen-miners.sh        # Arkreen sites: totals + 30-day rewards
node scripts/fetch-arkreen-monthly.mjs      # monthly generation per site (run after the line above)
node scripts/fetch-chain-snapshots.mjs      # Hypercerts + Sarafu pools (Blockscout)
node scripts/fetch-inat.mjs                 # INAT eco-credit sales
bash scripts/fetch-sarafu-reports.sh        # Sarafu activity reports
node scripts/fetch-silvi.mjs                # Silvi projects (needs API keys, see below)
```

**Silvi API keys.** Silvi issues one key per project (ask them at support@silvi.earth). Put them in a `.env` file at the repository root — it is git-ignored — one per line:

```
SILVI_KEY_MYPROJECT=silvi_...
```

See `.env.example`. Never commit keys.

## Adapt it for your own network

1. **Wallets and contracts** — `js/api.js` (`BLOCKCHAIN_CONFIG`): Arkreen owner addresses (also in `scripts/fetch-arkreen-miners.sh`), Hypercert contract and token IDs, INAT marketplace, Sarafu pools and vouchers, Giveth projects, Karma community slug, BirdWeather stations (`BIRD_STATIONS`).
2. **Map content** — `js/data.js`: ecovillages, solar stations, rainwater systems and Silvi projects.
3. **Texts and languages** — `js/i18n.js`. English is the source language and also the key: `T('English text')` returns the Ukrainian text when the UI is Ukrainian. To add a language, add a dictionary and extend the `detect()` function.

## Project layout

```
dashboard/
  index.html        page and static texts
  js/api.js         data sources, snapshot loaders, live fetches
  js/app.js         rendering of all blocks
  js/charts.js      Chart.js charts
  js/map.js         Leaflet map and layers
  js/i18n.js        EN / UK translations
  js/data.js        demo values and map points
  data/             JSON snapshots (generated by scripts/)
scripts/            snapshot generators
```

Local-only material (API keys in `.env`, notes in `private/`, raw data in `import/`) is git-ignored and never published.

## Analytics

The page includes the [Vercel Web Analytics](https://vercel.com/docs/analytics) snippet (cookie-less page-view counts). It only works when the site is hosted on Vercel with Web Analytics enabled; elsewhere it is a harmless 404. Remove the two `<script>` lines in `dashboard/index.html` if you fork and do not want it.
